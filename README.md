# このサイトを公開する前に

1. `index.html` と `privacy.html` 内の `CONTACT_EMAIL_REQUIRED@example.invalid` を**利用できる問い合わせ先メールアドレス**に両方置換する。
2. ウェブに公開する（例：Netlifyへ `public-site` フォルダのHTMLをアップロード）。
3. ブラウザでお問い合わせリンクとプライバシーポリシーを検証。
4. App Store Connectへ **Support URL** = `https://（自分の公開先）/`、**Privacy Policy URL** = `https://（自分の公開先）/privacy.html` を登録。
5. 上記がない場合、審査提出しない。サポート先のメールアドレスは仮の `.invalid` で意図的に機能しない。

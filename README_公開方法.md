# HALLWAVE サポートサイト公開方法

1. Netlifyにログインして、新しいサイトを作成。「Deploy manually」等で **public-site フォルダの中身**をアップロード。
2. Netlify管理画面の Forms で `hallwave-support` が検出され、フォーム受信が有効であることを確認。必要ならForms機能の有効化と通知先メールアドレス（自分の管理用）設定を行う。利用枠・スパム対策も確認。
3. 公開された `https://YOUR-SITE.netlify.app/` にアクセス。フォームにテスト送信し、Netlify Formsの管理画面で受信できることを**必ず**確認する。未受信なら審査提出しない。
4. `https://YOUR-SITE.netlify.app/privacy.html` と `/disclaimer.html` をブラウザで開いて表示確認。
5. App Store ConnectのSupport URLにはサイトトップ、Privacy Policy URLには `privacy.html` を登録。アプリ内から免責・プライバシー文章が読めることを確認する。
6. このZIPはローカルの制作物であり、実際のURLは未取得。公開先のドメインや公開完了を装わないこと。

**注意**：このサイトに問い合わせフォームを設置したので、アプリ自体が「外部通信なし」であっても、ユーザーがブラウザでサポートフォームを使う場合は個人情報が送信されます。公開後は現実の運用に合わせてプライバシーポリシーを調整してください。法務的な完全性や審査合格は保証できません。
